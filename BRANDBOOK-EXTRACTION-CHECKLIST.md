# Brandbook Extraction Checklist — Le Coquette Lux Spa

Use this before or during `webcraft:brief-intake` and `webcraft:discovery-questions`.

## Must Extract

- Official logo versions
- Primary color palette
- Secondary / accent colors
- Official typography
- Brand voice / tone guidance
- Visual references or mood direction
- Photography direction
- Iconography guidance
- Spacing / layout principles if provided
- Do-not-use rules

## Business / Messaging

- Core promise
- Brand positioning
- Target audience
- Premium/luxury cues the brand wants to own
- CTA priorities
- Service hierarchy

## Useful Questions To Resolve From The Brandbook

- Which color is the true primary brand color?
- Is `Manrope` truly the brand font or just the current website font?
- Should the tone feel more editorial-luxury, feminine-soft, medical-luxury, or high-fashion?
- Which visual elements are mandatory to preserve for recognition?
- Which current website elements are off-brand and should be removed?
